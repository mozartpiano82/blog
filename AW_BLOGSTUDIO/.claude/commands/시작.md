**원장님은 파일을 만들지 않습니다. 대화만 하십니다.** 파일은 전부 저희가 만듭니다.

## 먼저 확인

`00_내학원자료/01_기초정보/` 와 `10_학원위키/사례/` 를 확인해 지금 상태를 파악한다.

- 아무것도 없으면 → 아래 1단계부터
- 기초정보만 있으면 → 2단계부터
- 사례까지 있으면 → "준비 다 되셨어요" 하고 `/글쓰기` 를 권한다

## 1단계 — 학원 기본 정보 (대화로)

한 번에 다 묻지 말고 **하나씩** 묻는다. 답하시면 다음 걸 묻는다.

1. 학원 이름과 지역이 어떻게 되세요?
2. 무슨 과목, 어느 학년을 가르치세요?
3. 학부모가 문의하실 때 주로 어디로 연락하시나요? (카카오톡 / 전화 / 네이버 예약)
4. 다른 학원과 다르게 하시는 게 있다면 뭘까요? 운영 원칙 같은 거요.
5. 아이 성적이 안 오를 때, 원장님은 보통 **무엇부터 보세요?**
6. 학부모님께 **자신 있게 말씀하시는 것**과 **조심스럽게 말씀하시는 것**이 각각 뭐가 있을까요?

> 5·6번은 낯설게 들릴 수 있다. **왜 묻는지 먼저 말씀드린다.**
> 「글의 주제와 논리를 원장님 생각대로 짜려고 여쭤요. 말투만 비슷하고 생각이
> 다르면 원장님 글이 아니거든요.」
> 답이 잘 안 나오시면 **넘어간다.** 나중에 사례가 쌓이면 저절로 드러난다.

**답을 받으면 `00_내학원자료/01_기초정보/학원정보.md` 로 저장한다.**
원장님께는 "적어뒀습니다" 정도만 말하고 경로를 굳이 강조하지 않는다.

### 학원정보.md 는 이 모양으로 쓴다

담당들이 **자기 몫만 골라 읽는다.** 그래서 제목이 정해져 있어야 한다.
없는 항목은 아예 안 쓴다 — 빈 제목만 남기면 담당이 뭔가 있는 줄 안다.

```markdown
# <학원 이름>

## 지역
## 과목
## 대상
## 운영 방식        ← 5번 답. 원장님이 실제로 하시는 것
## 원장 소개
## 생각             ← 5·6번 답. 판단 기준과 말투가 아닌 **관점**
성적이 안 오르면 숙제부터 본다. 개념보다 습관을 먼저 의심한다.
자신 있게: 왜 틀렸는지 설명하게 시키면 는다
조심스럽게: 몇 점 오른다는 말은 안 한다
## 안 다루는 것     ← 여쭤서 나오면. 없으면 이 제목도 안 쓴다
다른 학원 비교, 입시 결과 자랑
```

**원장님 말씀을 요약하지 말고 그대로 옮긴다.** "습관을 먼저 의심한다" 를
"학습 태도 점검 우선" 으로 바꾸면 그 순간 원장님 글이 아니게 된다.

> 3번에서 여러 개를 말씀하시면 **하나만 고르시게** 한다.
> 학부모가 어디로 연락할지 헷갈리면 안 하기 때문이다.

## 2단계 — 말투 자료

```
원장님이 쓰신 글이 있으면 말투를 배울 수 있어요.
_여기에_넣으세요 폴더에 아무거나 넣어주세요. PDF든 워드든 상관없어요.
넣으셨으면 /정리 라고 쳐주세요.

없으셔도 괜찮아요. 예시 문체 세 가지 중에 고르시면 돼요.
```

없다고 하시면 프리셋 3종을 **예시 문단과 함께** 보여드리고 고르시게 한다.

| | 성격 | 예시 |
|---|---|---|
| A 담백한 정보형 | 짧은 문장, 표와 목록 | "중2 서술형 감점은 세 가지에서 나옵니다." |
| B 대화하듯 친근형 | 해요체, 거든요·더라고요 | "상담하다 보면 이런 질문 받거든요." |
| C 차분한 상담형 | 완화 표현이 많음 | "물론 모든 아이에게 맞는 방법은 아닙니다." |

## 3단계 — 사례 하나만

```
마지막이에요. 최근에 학원에서 있었던 일 하나만 들려주세요.
상담이든 수업이든 시험 결과든 뭐든 괜찮아요.
```

받으면 `/사례추가` 절차대로 처리한다.
