이 명령은 **Claude Code 안에서** 도는 설치 도우미입니다.
화면(대시보드)이 아직 안 뜨는 상태에서도 여기까지는 옵니다. 여기서부터 갖춰 나갑니다.

원장님은 **터미널을 모르는 분**이라고 가정하십시오. 명령어를 보여주지 말고,
무엇을 하고 있는지 한 줄씩 말하면서 대신 실행하십시오.

---

## 0. 어떤 컴퓨터인지 먼저 본다

```bash
uname -s 2>/dev/null || echo Windows
node --version 2>/dev/null || echo "NODE_NONE"
npm --version 2>/dev/null || echo "NPM_NONE"
claude --version 2>/dev/null || echo "CLAUDE_NONE"
```

결과를 이 표 그대로 원장님께 보여드립니다. **경로나 버전 문자열을 나열하지 마십시오.**

```
지금 컴퓨터를 살펴봤어요.

  Node.js       ✅ 있어요
  Claude Code   ✅ 있어요
  로그인        ✅ 돼 있어요
```

없는 항목만 아래 순서대로 처리합니다.

---

## 1. Node.js가 없을 때

**저희가 대신 설치할 수 없습니다.** 설치 중에 컴퓨터 비밀번호를 묻고,
그건 원장님만 아셔야 하는 것입니다. 절대 대신 입력하려 들지 마십시오.

맥이면 이렇게 안내합니다.

```
Node.js가 없어요. 이건 제가 대신 깔아드릴 수 없어요.
설치할 때 맥 비밀번호를 물어보거든요.

  1. https://nodejs.org/ko/download 를 열어주세요
  2. 초록색 LTS 단추를 누르면 .pkg 파일이 받아져요
  3. 받은 파일을 더블클릭하고 "계속"만 계속 누르시면 돼요
  4. 중간에 맥 비밀번호를 한 번 물어봐요
  5. 다 되면 저에게 "다 했어" 라고 말씀해 주세요
```

윈도우면 2번을 `.msi 파일`, 3번을 `"Next"만 계속`, 4번을 `"이 앱이 변경하도록 허용" 에 예`로 바꿉니다.

원장님이 다 하셨다고 하시면 `node --version` 을 다시 확인합니다.
**아직 안 잡히면** Claude Code를 껐다 켜셔야 한다고 알려드립니다 (PATH가 새로 읽혀야 합니다).

---

## 2. Claude Code가 없을 때

이건 대신 해드릴 수 있습니다. 먼저 무엇을 할지 말하고 실행합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

권한 오류(`EACCES`)가 나면 `sudo` 로 다시 시도하지 **마십시오.**
대신 이렇게 안내합니다.

```
설치할 권한이 없다고 나와요. 두 가지 방법이 있어요.

  쉬운 쪽: https://claude.com/download 에서 앱으로 받으시면 돼요
  다른 쪽: 터미널에서 아래 한 줄을 직접 쳐주세요 (비밀번호를 물어봐요)
           sudo npm install -g @anthropic-ai/claude-code
```

## 3. 로그인이 안 돼 있을 때

확인은 이렇게 합니다.

```bash
claude -p "1 더하기 1은?" 2>&1 | head -5
```

답이 오면 됐습니다. 인증 오류가 나면 **터미널에서만** 됩니다.

```
로그인은 검은 명령 창에서만 돼요. 제가 대신 못 해요.

  1. 아래 창을 열어드릴게요
  2. 거기에 claude 라고 치고 엔터를 누르세요
  3. 브라우저가 열리면 Claude 계정으로 로그인하세요
  4. "Login successful" 이 뜨면 그 창을 닫으셔도 돼요
  5. 저에게 "다 했어" 라고 말씀해 주세요

Claude Pro 또는 Max 구독이 있으셔야 해요.
```

창을 열어드립니다.

```bash
# 맥
open -a Terminal .
# 윈도우
start cmd /K "cd /d %CD%"
```

## 4. 다 갖춰지면 화면을 띄운다

```bash
node bin/lib/ui.mjs . &
```

브라우저가 저절로 열립니다. 안 열리면 주소를 알려드립니다.

```
준비 다 됐어요. 브라우저에 화면이 열렸을 거예요.

안 열렸으면 주소창에 이걸 넣어주세요 — http://localhost:4321

다음부터는 이 폴더의 "BlogStudio" 를 더블클릭하시면 바로 열려요.
저를 거치지 않으셔도 돼요.
```

그다음 화면 **설정** 칸에서 학원 정보부터 채우시라고 안내하고 끝냅니다.

## 하지 말 것

1. **비밀번호를 대신 입력하지 않는다.** 물어보지도 않는다
2. **`sudo` 를 마음대로 쓰지 않는다.** 원장님이 직접 치셔야 한다
3. **명령어를 그냥 보여주고 끝내지 않는다.** 대신 실행할 수 있는 건 대신 한다
4. **경로·버전 문자열을 나열하지 않는다.** 됐는지 안 됐는지만 말한다
5. 안 되면 **솔직히 안 된다고 말한다.** 됐다고 넘어가면 다음 단계에서 더 크게 터진다

## 이미 다 갖춰져 있으면

확인만 하고 바로 화면을 띄웁니다. 설치 이야기로 시간을 쓰지 않습니다.
