# 네이버 블로그 검색 가이드 — 작성 에이전트용 규칙서

> **이 문서의 성격.** 해설서가 아니라 **판정 규칙서**다.
> 작성자 에이전트가 지켜야 할 것, 검수기가 기계로 잴 수 있는 것만 담는다.
> 모든 규칙에 네이버 공식 문장 근거가 있다. 근거 없는 업계 속설은 넣지 않는다.

---

## 0. 대전제 — 이것부터 틀리면 나머지가 무의미하다

**네이버는 "잘 쓴 글"이 아니라 "검색한 사람의 질문에 실제로 답한 글"을 찾는다.**

> "블로그 검색 노출 기준은 여러 요소를 종합한 **관련도**로서, 이 기준에 더욱 부합할 시
> 오래된 글이 최신 글보다 먼저 노출될 수 있습니다." (블로그 고객센터)

따라서 작성 순서를 뒤집는다.

| 흔한 순서 | 이 제품의 순서 |
|---|---|
| 제목 고름 → 사진 넣음 → 분량 채움 | **질문 적음 → 답을 3줄로 씀 → 근거·사례 붙임 → 제목은 마지막** |

**부정 근거도 규칙이다.**

> "저품질 블로그, 최적화 블로그, 블로그 지수 등은 **네이버에서 만든 개념이 아닙니다**."
> "특정 키워드로 검색 시 항상 상위에 노출되는 **천하무적 블로그란 존재하기 어렵습니다**."

→ 에이전트는 "상위노출 보장", "최적화 블로그", "블로그 지수" 같은 표현을
사용자에게도 글에도 쓰지 않는다. 근거 없는 개념이다.

## 1. 랭킹 2축 — C-Rank(출처) × D.I.A.+(문서)

두 알고리즘은 **상호 보완**이다. 하나만 맞춰서는 안 된다.

### C-Rank — 출처(블로그)의 신뢰도

> "해당 블로그가 주제별 관심사의 **집중도**는 얼마나 되고(Context),
> 생산되는 정보의 **품질**은 얼마나 좋으며(Content),
> 생산된 콘텐츠는 어떤 **연쇄반응**을 보이며 소비/생산되는지(Chain)를 파악해
> 이를 바탕으로 얼마나 믿을 수 있고 인기 있는 블로그인지(**Creator**)를 계산합니다."

**결정적 문장:**

> "**의무적으로 포스팅되는 일상 글보다는 전문성을 살린 단 하나의 글이
> 블로그 검색 결과 노출에 더 도움** 될 것"
>
> "다양한 일상 주제에 대한 포스트보다는 **특정 주제에 대한 자신만의 포스트가 늘어날수록**
> 검색 결과에서는 더 잘 노출"

**→ 에이전트 규칙 C1~C4**

| # | 규칙 | 검수 방법 |
|---|---|---|
| C1 | 한 블로그는 **주제를 좁게** 유지한다. 최근 10편의 주제가 3개 이내 | `발행이력.md`의 주제 태그 분포 계산 |
| C2 | 일상·공지·이벤트 글이 최근 10편의 **절반을 넘지 않는다** | 발행이력 유형 카운트 |
| C3 | 새 글은 블로그의 **기존 주제 축과 이어져야** 한다. 축을 벗어나면 경고 | 소재 선정기가 wiki 주제축과 대조 |
| C4 | 같은 주제를 **오래 반복**한다. 3개월 전 글과 이번 주 글이 같은 축이어야 강한 누적 | 발행이력 3개월 구간 비교 |

### D.I.A.+ — 문서 자체의 정보성

> "**D.I.A.**(Deep Intent Analysis)란, 네이버의 데이터를 기반으로 키워드별로
> 사용자들이 선호하는 문서들에 대한 점수를 랭킹에 반영한 모델"
>
> 반영 요소: "문서의 **주제 적합도, 경험 정보, 정보의 충실성, 문서의 의도,
> 상대적인 어뷰징 척도, 독창성, 적시성**"

**결정적 문장:**

> "많은 검색 사용자들은 대체적으로 **본인이 실제 경험한 체험기**,
> 누구나 선호할만한 **상세한 정보**, 특정분야의 **깊이 있는 의견** 등을 좋아하는 것으로 보여집니다."
>
> "**비체험 후기는 학습데이터가 랭킹을 밀어냅니다.**"
>
> D.I.A.+가 대응한 사용자 불만: "제목과 설명만 보고 클릭했더니,
> **실제 원하는 정보는 없는 낚시성 글**이었다"

**→ 에이전트 규칙 D1~D5**

| # | 규칙 | 검수 방법 |
|---|---|---|
| D1 | **제목이 약속한 정보가 본문에 실제로 있어야** 한다. 이게 D.I.A.+의 핵심 판정 | 제목의 질문 ↔ 본문 답변 문단 매칭 |
| D2 | **직접 경험 서술이 반드시 들어간다.** 학원 wiki의 실제 사례가 근거 | wiki 사례 인용 0건이면 반려 |
| D3 | 일반론만으로 채운 글은 금지. **외부 유래 일반론 30% 상한** | 문단별 출처 태깅 후 비율 계산 |
| D4 | **구체 수치·기간·횟수**를 넣는다 (기간, 횟수, 점수, 인원) | 숫자 포함 문장 수 ≥ 3 |
| D5 | 발행 주기는 랭킹과 무관하다. 억지로 매일 쓰지 않는다 | — (사용자 안내용) |

> D5 근거: "D.I.A. 모델 적용은 사실상 **개별 문서 단위의 품질만 보기 때문에
> 출처별 글 작성 주기와는 관련성이 없습니다**."

## 2. 제목 규칙

### 필수 (T-MUST)

| # | 규칙 | 근거 |
|---|---|---|
| T1 | **명확하고 간결**하게. 글 내용을 대표할 것 | "가급적 명확하고 간결한 제목이 좋습니다" |
| T2 | 학부모가 **실제로 물어본 문장** 형태를 우선한다 | D.I.A.+ 질의 의도 분석 |
| T3 | 검색어는 **자연스럽게 1회** 포함 | — |

**좋은 예 / 나쁜 예** (원장님 강의 1강)

```
✗ 정성으로 지도하는 우리 학원 중등부 안내
✓ 중2 영어 성적이 갑자기 떨어졌을 때 먼저 확인할 3가지
```

### 금지 (T-NEVER) — 위반 시 검수기가 무조건 반려

| # | 금지 | 근거 |
|---|---|---|
| T4 | **같은 검색어 반복** ("수분크림" 5회 같은 패턴) | "인위적으로 검색어를 넣어 작성된 문서는 검색 사용자의 선호도가 떨어지기 마련이고 (…) 후순위로 밀려납니다" |
| T5 | **지역명·서비스명 나열** | "제목에 나열하면 (…) 그 내용의 정확도나 전문성 등 전반적인 품질이 높지 않을 것이라고 예상합니다" |
| T6 | **본문과 무관한 문구 삽입** (홍보 문구·업체명) | "내용과 연관성이 적은 문구를 제목에 사용한 점에서 (…) **낚시성 문서로 분류될 수 있습니다**" |
| T7 | **모든 글 제목에 같은 문구 반복** | "모든 포스트 제목에 특정 문구가 반복 사용된 사례" — 제재 사유 |
| T8 | **의미 없는 특수문자·유니코드 문자** | "검색 결과에서 정보가 아닌 다른 요소를 사용해 시각적인 주목도를 높여 다른 문서의 가독성을 저해하는 문서는 **어뷰징 문서로 규정**" |

> **속설 차단.** "제목에 특수문자를 넣으면 검색 결과에 더 잘 나온다"는
> "**사실과 전혀 다를 뿐만 아니라 (…) 반대로 좋지 않은 영향**을 주며,
> 일부 불법 홍보에 활용되는 패턴으로 알려져 있"다.

### 기계 판정 규칙 (검수기 구현용)

```
T4  동일 명사구가 제목 내 2회 이상        → 반려
T5  쉼표/슬래시로 구분된 지역·서비스 3개+ → 반려
T7  최근 10편 제목의 공통 부분문자열 5자+ → 경고
T8  제목 내 특수문자(문장부호 제외) 2개+  → 반려
     허용: ? ! . , ~ ( ) 및 숫자
     차단: ★ ♥ ▶ ◆ ■ ▣ 등 장식 기호, 비표준 유니코드
```

## 3. 본문 규칙

### 구조 (B1~B5)

| # | 규칙 |
|---|---|
| B1 | **첫 문단에 답을 먼저** 쓴다. 4줄 틀 — ①질문 확인 ②짧은 답 ③왜 그런지 ④이 글에서 다룰 것 |
| B2 | 나열 대신 **문단·표로 정리**한다 |
| B3 | 학원 고유 사례를 **본문 중반에** 배치한다 (근거 위치) |
| B4 | 판단을 돕는 장치를 넣는다 — 비교표, 체크리스트, 질문형 소제목 |
| B5 | 끝에 **다음 행동 하나**를 제시한다 (CTA는 1개, 창구도 1개) |

> B2 근거: "굳이 제목에 검색어를 나열하지 않더라도 **본문에서 문단이나 표 등을 활용해
> 잘 정리하면 검색 결과에도 잘 나올 수 있고 실제 정보 전달력 또한 높일 수 있어 훨씬 효과적**"

### 절대 금지 (B-BAN) — 블로그 **전체**가 검색 제외될 수 있음

| # | 금지 | 근거 |
|---|---|---|
| B6 | **프로그램을 이용한 기계적 포스팅** | "특유의 작성 패턴을 보이기 마련이고, 이러한 패턴을 감지하는 시스템에 의해 결국 **해당 블로그 포스트 전체가 검색 결과에서 제외**됩니다" |
| B7 | **숨긴 텍스트** — 흰 글씨, 초소형 글자, 높이 0 테이블 | "이러한 패턴으로 작성된 블로그는 시스템에 의해 비정상적인 문서로 판별되어 마찬가지로 **검색 결과에서 제외**됩니다" |
| B8 | 검색 노출을 위해 **사실과 다른 내용** 삽입 | 낚시성 문서 정의 |
| B9 | 유해문서 — 저작권 침해 이미지, 개인정보 노출 | 유해문서 정의 |

> **B6은 이 제품의 존재 이유와 직결된다.** 네이버가 잡아내는 것은 *AI 사용*이 아니라
> *기계적 작성 패턴*이다. 그래서 윤문기(문장 길이 분산·종결어미 분포 복원)와
> 원장 고유 사례 강제가 기능이 아니라 **안전장치**다.

## 4. 이미지와 태그

| # | 규칙 | 근거 |
|---|---|---|
| I1 | **이미지 안 텍스트는 검색이 못 꺼낸다.** 카드형 이미지만으로 채우지 않는다 | "이미지 안에 있는 텍스트를 꺼낼 수 없기 때문에 (…) 검색 노출되는 데에는 한계" |
| I2 | 이미지 위주 글이면 **하단에 텍스트 요약**을 반드시 넣는다 | "마지막장 혹은 하단에 해당 포스트의 요약 내용을 (…) 텍스트로 넣어주시는 걸 강력 추천" |
| I3 | 이미지 캡션에 **제목과 같은 문구를 반복하지 않는다** | 어뷰징 사례로 명시됨 |
| I4 | 태그는 **"이 키워드로 검색됐으면" 하는 말**로 신중히 넣는다 | "태그가 (…) 글을 전파해주는 연결고리" |
| I5 | **저작권 침해 이미지 금지.** 직접 촬영 우선 | 유해문서 정의 |

> **이 제품의 이미지 방침(계획서 D3).** 이미지를 생성하지 않는다.
> 본문에 `[사진 자리 ①: 촬영 지시문]`을 남기고 원장이 실물 사진을 넣는다.
> **직접 촬영 사진이 D.I.A.+의 "경험 정보" 신호로 더 강하다.**

## 5. 유사문서 — 이 제품 최대 리스크

> "'**유사문서 판독시스템**'이란 서로 유사한 내용을 가진 문서가 있는 경우,
> **원본글과 복사글(유사문서)로 구분해 보여주는 시스템**입니다."
>
> "한 번 유사문서로 판독되더라도 **주기적으로 다시 판독** 과정을 거치는데요"

**같은 프로그램을 쓰는 학원끼리 글이 닮으면 서로를 죽인다.**

| # | 규칙 | 검수 방법 |
|---|---|---|
| S1 | 본문 근거는 **학원 고유 사례**에서만 나온다 | wiki 인용 0건 → 반려 |
| S2 | 외부 유래 일반론 **30% 상한** | 문단 출처 태깅 |
| S3 | 스크랩 **원문 복제 금지** | 원문 대비 3-gram 중복률 |
| S4 | 과거 내 글과의 **자기복제 금지** | `발행이력.md` 대비 3-gram |
| S5 | 구조 템플릿 **8종 이상**을 학원별 시드로 분산. 연속 2회 같은 틀 금지 | 발행이력 템플릿 ID 확인 |

**출시 판정 기준:** 학원 3곳 동일 주제 글의 상호 **3-gram 중복률 15% 미만**.

## 6. AI 검색 시대의 추가 규칙

출처: `2608 검색대란_상위노출특강` — 네이버 공식 발표 5건 인용분

**변화 요약**

| 이전 | 지금 |
|---|---|
| 검색 = 링크 나열 | 검색 = **답변 + 출처**. AI가 추천하고 연결 |
| 키워드 일치 | **맥락 적합성** |
| 클릭 이후 승부 | **클릭 이전 판단**에서 승부 |
| 연관검색어로 키워드 확장 | 연관검색어 **서비스 종료**. 질문 흐름을 잡아야 함 |

### 6-1. 무엇에 답하는가 — A1~A4

| # | 규칙 |
|---|---|
| A1 | 글은 **학원 이름**이 아니라 **학부모의 결정 고민**에 답한다. AI가 읽는 것은 후자다 |
| A2 | **질문형 제목 + 표**로 판단 비용을 낮춘다. AI 인용 단위가 되기 쉽다 |
| A3 | 주장마다 **근거(운영의 흔적)**를 붙인다. 흔적이 없으면 학부모도 AI도 판단 못 한다 |
| A4 | 소개글이 아니라 **판단을 돕는 글**로 쓴다. 같은 소재라도 목적을 바꾸면 다른 글이 된다 |

### 6-2. 어떤 모양이어야 떠가는가 — A5~A8

가장 중요한 전제부터. **AI는 글을 통째로 인용하지 않는다.**
질문 하나에 답 하나가 붙은 **덩어리**를 떠간다. 그 덩어리가 글 안에 없으면
아무리 잘 쓴 글도 인용되지 않는다. 순위와 인용은 다른 싸움이다.

| # | 규칙 | 검수 |
|---|---|---|
| A5 | 소제목을 **학부모가 실제로 묻는 말투**로 쓴다. "감점의 원인"이 아니라 "답은 맞았는데 왜 깎이나요" | `G2` |
| A6 | 글마다 **표를 최소 하나** 넣는다. 선택지 비교, 학년별 차이, 시기별 할 일 무엇이든. 표는 AI가 통째로 떠가는 가장 싼 단위다 | `G1` |
| A7 | 질문형 소제목 **바로 아래 두세 문장에서 답을 먼저 끝낸다.** 근거와 사례는 그다음 문단으로 민다. 답이 여러 문단에 걸치면 떠갈 덩어리가 없다 | `G3` |
| A8 | 한 글에 **질문 세 개 이하**. 질문을 늘리면 각 답이 얕아져서 어느 것도 인용 단위가 못 된다 | — |

> **역피라미드가 되돌아왔다.** 사람이 읽는 글은 궁금증을 끌고 가도 되지만,
> AI가 읽는 글은 답이 앞에 있어야 한다. 두 독자를 동시에 만족시키는 방법이
> "소제목에서 묻고, 바로 아래에서 답하고, 그다음에 왜인지 풀기"다.

### 6-3. 누가 말했는가 — A9~A12

AI는 **누가 말했는지**로 인용 여부를 가른다. 같은 문장이라도
출처가 없으면 안 떠간다. C-Rank의 Creator가 여기서 다시 걸린다.

| # | 규칙 |
|---|---|
| A9 | 숫자에는 **범위와 조건**을 붙인다. "성적이 올랐다"가 아니라 "중2 여덟 명 중 다섯 명이 한 학기 뒤 서술형 감점이 절반으로 줄었다". 조건 없는 숫자는 AI가 안 쓴다 |
| A10 | 학원 이름·지역·과목을 **글마다 한 번은** 자연스럽게 적는다. 브랜드 언급 빈도가 AI의 실체 인식 신호다. 단 반복 나열은 T5 위반이다 |
| A11 | **직접 겪은 것과 들은 것을 구분해 쓴다.** "저희 학원에서는", "학부모님께 들은 이야기로는". 경험의 출처가 붙은 문장이 인용된다 |
| A12 | 이어지는 글은 **서로를 가리킨다.** 같은 주제의 앞 글을 한 줄로 언급한다. C-Rank의 Chain이자 AI가 주제 권위를 재는 신호다 |

> **하지 말 것.** llms.txt, robots 조작, AI용 별도 페이지 같은 것은 이 제품에서 다루지 않는다.
> 네이버 블로그는 그런 파일을 올릴 수 없고, 티가 나는 최적화는 어뷰징으로 분류된다.
> 여기서 말하는 GEO는 **글 자체의 모양**을 바꾸는 것뿐이다.

> ⚠️ **사실과 해석의 경계.** AI탭이 모든 검색에 자동으로 뜨는지, AI 브리핑이 항상 뜨는지는
> 공식 문서로 확인되지 않는다. 말할 수 있는 범위는 "진입 구조가 공식적으로 확인된다"까지다.
> 에이전트는 이 범위를 넘어 단정하지 않는다.

## 7. 검수기 체크리스트 (기계 판정)

작성 후 자동으로 도는 항목. **하나라도 걸리면 재작성.**

```
[제목]
  □ T4 동일 명사구 2회 이상             → 반려
  □ T5 지역·서비스 나열 3개 이상        → 반려
  □ T7 최근 10편과 공통 문구 5자 이상   → 경고
  □ T8 장식 특수문자 2개 이상           → 반려

[본문]
  □ D1 제목의 질문에 답하는 문단 없음   → 반려
  □ D2 wiki 사례 인용 0건               → 반려
  □ D3 외부 유래 일반론 30% 초과        → 반려
  □ D4 구체 수치 포함 문장 3개 미만     → 경고
  □ B1 첫 문단에 답 없음                → 반려
  □ B5 CTA 2개 이상                     → 경고
  □ B7 숨김 텍스트 패턴                 → 반려

[유사문서]
  □ S3 스크랩 원문 3-gram 중복 초과     → 반려
  □ S4 과거 내 글 3-gram 중복 초과      → 반려
  □ S5 직전 글과 같은 구조 템플릿       → 경고

[이미지]
  □ I2 이미지 위주인데 텍스트 요약 없음 → 반려
  □ I3 캡션이 제목 문구 반복            → 반려
```

임계값(3-gram 중복률 등)은 M6 파일럿 실측으로 확정한다. **지금 값은 잠정이다.**
