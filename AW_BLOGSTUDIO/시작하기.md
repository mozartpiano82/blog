# 시작하기

**읽으실 건 이 한 장뿐이에요.** 나머지는 대화로 하시면 돼요.

---

## 1. 시작하는 법 — 문이 두 개예요

**아무거나 편한 쪽으로 하시면 돼요. 같은 화면이 열려요.**

### 문 ①. Claude Code 안에서 (이쪽을 권해요)

**Claude Code 데스크톱 앱**을 열고 **이 폴더를 여신 다음**, 입력창에 이렇게 치세요.

```
/스튜디오
```

**오른쪽에 화면이 열려요.** 왼쪽은 대화, 오른쪽은 화면이에요.

이쪽이 편한 이유가 있어요.

- 창을 왔다 갔다 안 하셔도 돼요. **한 화면 안에서 다 돼요**
- 대화는 위로 밀려 올라가지만 **오른쪽 화면은 그대로 있어요.**
  쓸 사례가 몇 건인지, 지난 글이 뭐였는지 매번 다시 물어보실 필요가 없어요
- 글 쓰는 20분 동안 **지금 어디까지 왔는지**가 오른쪽에 보여요

준비가 안 됐다고 하면 이렇게 치세요. 컴퓨터를 살펴보고 없는 걸 챙겨드려요.

```
/설치
```

> 왜 전부 자동이 아닌가요 — Node.js는 설치할 때 **컴퓨터 비밀번호**를 물어봐요.
> 그건 원장님만 아셔야 하는 거라 저희가 대신 칠 수 없어요. 대신 순서를 아주 자세히 알려드려요.

### 문 ②. 아이콘을 눌러서

이 폴더에서 아래 파일을 **더블클릭**하세요. 브라우저에 화면이 열려요.

| 쓰시는 컴퓨터 | 누를 파일 |
|---|---|
| 맥 | `BlogStudio.command` |
| 윈도우 | `BlogStudio.bat` |

> 맥에서 처음 누르실 때 "확인되지 않은 개발자" 경고가 뜨면,
> 파일에 **마우스 오른쪽 클릭 → 열기**를 한 번만 해주시면 다음부터는 그냥 열려요.

이쪽으로 여셔도 글은 똑같이 써져요. 다만 **글을 쓰려면 Claude Code가 깔려 있어야 해요.**
화면만 열리고 글쓰기가 안 되면 문 ①로 가세요.

### 있어야 하는 것

| | |
|---|---|
| Node.js | **22 버전 이상** (https://nodejs.org 에서 LTS) |
| Claude Code | 설치하고 로그인 (Pro 또는 Max 구독) |

### 따로 깔 스킬이나 플러그인은 없어요

글쓰기 방법, 검수 규칙, 지식 파일이 **이 폴더 안에** 다 들어 있어요.
원장님 컴퓨터의 다른 Claude 설정과 상관없이 똑같이 돌아요.

## 2. 처음 한 번 — 30분

화면을 열면 **네 단계가 순서대로 나와요.** 그대로 따라가시면 돼요.

| 단계 | 뭘 하나 | 얼마나 |
|---|---|---|
| **1** 학원 정보 알려주기 | 칸을 채우고 저장 | 5분 |
| **2** 자료 넣기 | 파일을 화면에 끌어다 놓기 | 5분 |
| **3** 정리하기 | 단추 한 번 | 3~5분 (저희가 해요) |
| **4** 첫 글 쓰기 | 주제 적고 단추 | 20~30분 (기다리지 않으셔도 돼요) |

**1단계는 학원 이름만 있어도 넘어가요.** 나머지는 나중에 채우셔도 돼요.

**2단계 — 파일은 화면에 그냥 끌어다 놓으세요.**

> 예전 블로그 글, 학원 소개서, 브로슈어, 학부모 안내문, 상담 자료,
> 카카오톡 대화 내보내기 — **PDF·워드·한글 다 읽어요.**
> 파일 이름도 신경 안 쓰셔도 돼요. 창 아무 데나 떨어뜨리셔도 들어가요.

**많이 넣으실수록 원장님 말투를 정확히 배워요.** 없으셔도 넘어가실 수 있어요.

**3단계 정리가 끝나면 반드시 확인 화면이 떠요.**

저희가 자료를 읽고 정리한 거라 **사실과 다를 수 있어요.**
학생 이야기가 잘못 적혔거나, 없던 내용이 섞였을 수 있어요.
**여기서 고치신 내용이 앞으로 모든 글의 근거가 돼요.** 한 번만 봐주세요.

- 틀린 곳 → **열어서 고치기**
- 아예 잘못 들어온 것 → **지우기** (되살릴 수 있게 휴지통으로 가요)

## 2-1. 나중에 고치고 싶으실 때

**내 자료** 탭에 다 있어요. 언제든 고치고 지우실 수 있어요.

| 고치고 싶은 것 | 어디 |
|---|---|
| 학원 이름, 지역, 문의 창구 | 내 자료 → **학원 정보 고치기** |
| 학생 사례 내용 | 내 자료 → **사례** → 열어서 고치기 |
| 말투 기준 숫자 | 내 자료 → **말투 기준** |
| 잘못 올린 파일 | 내 자료 → **아직 정리 안 된 것** → 지우기 |

지우신 건 `.휴지통` 폴더에 남아요. 실수하셔도 되살릴 수 있어요.

## 3. 글 쓰기

```
/글쓰기 중2 서술형 감점
```

이거 하나면 끝나요. **20~30분쯤 걸려요** — 담당이 여섯 번 나눠 맡거든요.
기다리지 않으셔도 돼요. 창을 닫으셔도 계속 하고, 다 되면 알려드려요.

### 누구에게 쓸지 고르고 싶으시면

화면의 **누구에게 쓸지 고르기**를 펴면 세 가지를 고를 수 있어요.
**안 고르셔도 돼요** — 그러면 알아서 정해요.

| 고르는 것 | 무엇 |
|---|---|
| 학부모 상태 | 정보형 · 비교형 · 선택형 · 불안형 — 지금 어떤 마음으로 검색하는지 |
| 글유형 | 설명형 · 비교형 · 사례형 · 상담전환형 — 어떻게 설명할지 |
| 블로그의 자리 | 시작시기 · 비교기준 · 성적문제 · 사례 · 상담준비 · FAQ |

상태를 고르면 맞는 글유형에 ★ 표시가 붙어요. 강의에서 배우신 그 체계 그대로예요.
"아직 없어요"라고 표시된 자리부터 채우시면 블로그가 빨리 갖춰져요.

**뭘 쓸지 모르시겠으면 두 가지가 있어요.**

```
/글감수집
```

요즘 학부모들이 뭘 궁금해하는지 **웹을 한 바퀴 돌고 와서** 알려드려요.
시험 기간이라 지금 검색이 몰리는 주제, 최근 바뀐 제도, 맘카페에서 자주 나오는 질문 같은 것들이요.

찾아온 건 **글감 창고**에 쌓여요. 지금 안 쓰셔도 다음 달에 쓰시면 돼요.
마음에 드는 걸 고르시면 바로 글로 만들어 드려요.

> 자동으로 글을 쓰지는 않아요. **찾아서 보여드리기만** 하고, 고르시는 건 원장님이에요.

```
/제안
```

이건 웹을 안 보고, **원장님이 이미 쓰신 글들**을 보고 말을 걸어요. *"최근 여섯 편이 다 중2였어요. 다른 학년도 하나 어떠세요?"*
*"한동안 안 쓴 사례가 세 건 있어요."* *"요즘 눈에 들어온 기사나 유튜브 링크 있으세요?"*

키워드든 링크든 그냥 떠오른 생각이든 던지시면 학원 사례와 엮어 기획해 드려요.

## 4. 완성된 글 보기

글이 다 되면 **어디에 있는지, 뭘 하시면 되는지 화면에 알려드려요.**

```
📄 완성글
   20_완성글/2026-08-24_중2서술형/최종.md   ← 더블클릭하면 열려요
```

| 파일 | 뭘로 열리나 | 언제 쓰나 |
|---|---|---|
| `최종.md` | 메모장 (더블클릭) | **네이버에 복사해 붙일 때** |
| `최종.html` | 브라우저 (더블클릭) | 블로그에서 보이는 모습 미리 볼 때 |

**원래 컴퓨터에 있는 걸로 열려요.** 따로 설치하실 게 없어요.

### 네이버에 올리실 때 세 가지

1. `최종.md` 열어서 **본문만 복사** → 네이버 블로그에 붙여넣기
2. 글 안에 `[사진 자리 ①: ...]` 표시가 있어요. **거기에 직접 찍으신 사진**을 넣어주세요
3. 맨 아래 **"이 글은 이렇게 썼습니다"** 부분은 원장님만 보시는 메모예요. **빼고 올리세요**

> 사진은 직접 찍으신 게 훨씬 강해요. 만들어낸 이미지보다요.
> **학생 이름과 얼굴은 반드시 가리고** 찍어주세요.

## 5. 고치신 걸 알려주기 ★ 여기가 핵심이에요

블로그에 올리기 전에 손보시죠. **그 고친 걸 알려주시면 배워요.**

```
/피드백
```

고치신 글을 붙여넣거나 파일로 주시면 돼요.

- 지우신 표현 → 앞으로 이 표현은 빼고 써요
- 직접 넣으신 표현 → **원장님 시그니처로 등록**하고 브랜딩 문장으로 써요
- 문장을 쪼개셨는지 합치셨는지, 어미를 어떻게 바꾸셨는지도 봐요

한 번에 확정하지 않아요. **두 번 이상 같은 패턴이 나와야** 반영하고, **반영 전에 여쭤봐요.**

> **편집률**을 매번 알려드려요.
> 이 숫자가 줄어들면 원장님 톤에 가까워지고 있다는 뜻이에요.
> 늘어나면 저희가 어긋나고 있다는 뜻이에요.
>
> 이게 이 프로그램의 핵심이에요. **쓸수록 원장님 글에 가까워져요.**

깜빡하셔도 돼요. 다음에 `/글쓰기` 하실 때 저희가 먼저 여쭤봐요.

## 6. 사례 채우기 — 주 1회 5분

```
/사례추가 지난주에 지훈이가 서술형에서 조건을 계속 놓쳐서
         밑줄 긋는 연습을 2주 시켰더니 감점이 절반으로 줄었어요
```

편하게 적으시면 돼요. 학생 이름은 저희가 가려요.

**사례가 곧 글감이에요.** 한 달 돌리려면 5개쯤 있으면 좋아요.
글감이 떨어지기 전에 저희가 먼저 알려드려요.

## 화면 네 칸 — 글 쓰는 순서 그대로

| 칸 | 여기서 하는 일 |
|---|---|
| **글쓰기** | 주제 적고 글 쓰기 · 누구에게 쓸지 고르기 · 글감 찾아오기 · 제안받기 |
| **내 글** | 다 쓴 글 보기·복사 · 어떤 학년·형식에 몰렸나 · 조회수 붙이기 · 고친 걸 알려주기 |
| **자료** | 뭐든 넣기 · 넣은 게 어디로 갔나 · 담긴 것 고치기 · 배운 말투 |
| **설정** | 처음 세팅 · 학원 정보 · 자료 옮기기 · 새 판 받기 · 고장 신고 |

**매주 쓰시는 건 앞의 두 칸이에요.** 자료와 설정은 처음에 한 번, 그다음엔 가끔이에요.

**모르는 게 나오면 제목 옆 `?` 를 눌러보세요.** 그게 뭔지, 숫자를 어떻게 읽는지 알려드려요.

## 완성된 글을 노션에 쌓고 싶으시면

> **아직 열어드리지 못한 기능이에요.** 저희가 실제 노션 계정으로 끝까지
> 확인하지 못해서 화면에서 감춰뒀어요. 확인이 끝나면 업데이트로 열어드릴게요.
> 아래는 열렸을 때를 위한 안내예요.


**설정 → 노션에 쌓기** 에 안내가 있어요. 한 번만 하시면 되고 5분쯤 걸려요.

| | |
|---|---|
| 따로 설치할 것 | **없어요.** 노션 앱도 MCP도 필요 없어요 |
| 필요한 것 | 노션 열쇠 하나, DB 페이지 주소 하나 |
| 가는 것 | 본문(소제목·표까지) + 제목·날짜·글유형·학생군·조회수 |
| 자동으로 | **안 보내요.** 완성된 글에서 단추를 누르실 때만 |
| 한 방향 | 프로그램 → 노션. **노션에서 고쳐도 프로그램은 몰라요** |

> **가장 많이 막히는 곳.** 열쇠를 만든 다음 **그 DB 페이지에서 `⋯` → 연결 → 통합 선택**을
> 꼭 해주세요. 이걸 빠뜨리면 열쇠가 맞아도 "DB를 못 찾았어요"가 나와요.
> 노션은 통합에게 페이지를 하나씩 열어주는 구조예요.

열쇠는 `.연결설정.json` 한 파일에만 있어요. **자료 내보내기에는 안 담겨요.**
그래서 새 컴퓨터에서는 다시 연결해주셔야 해요.

## 자료를 지키는 법

원장님 자료는 **이 컴퓨터에만** 저장돼요. 저희 서버는 없어요.
로그인도 비밀번호도 없고, 다른 사람 자료와 섞일 일도 없어요.

**다만 한 가지는 알고 계셔야 해요.**

글을 쓸 때는 Claude(클로드)라는 AI가 글을 씁니다. 그래서 **글 쓰는 그 순간에는
학원 정보와 사례가 Claude 서비스로 전송돼요.** 인터넷이 필요한 이유가 이거예요.

| | |
|---|---|
| **컴퓨터에만 남는 것** | 원장님이 넣으신 원본 파일, 사례 카드, 완성된 글, 발행 기록 |
| **글 쓸 때 Claude로 가는 것** | 그 글에 쓰이는 학원 정보·사례·말투 자료 |
| **아무 데도 안 가는 것** | 원장님 계정 정보 (애초에 저희가 안 받아요) |

그래서 `/정리`가 **학생 이름·전화번호·학교명을 옮기기 전에 가려요.** ○○중 3학년
형태로 바꿔서 카드를 만들어요. 원본은 그대로 두고요.

전송된 내용을 Claude가 어떻게 다루는지는 Anthropic의 개인정보 방침을 따라요.
**주민번호·계좌번호·학부모 연락처처럼 정말 민감한 건 애초에 넣지 마세요.**
저희가 다 가려낸다고 장담 못 해요.

**그래서 컴퓨터가 바뀌면 그대로 사라져요.**

`자료 넣기 → 자료 지키기 → 자료 묶어서 내보내기` 를 가끔 눌러
나온 zip을 USB나 메일에 옮겨두세요. 새 컴퓨터에서는 그 zip을 화면에 끌어다 놓으면 되살아나요.

## 이 프로그램이 걸러주는 것

원장님이 신경 안 쓰셔도 알아서 걸러요.

| | |
|---|---|
| **위험할 수 있는 표현** | "최고", "1등", "성적 보장", "3개월 만에 30점" |
| **학생 개인정보** | 실명, 학교명이 그대로 나가는 것 |
| **AI 티** | 상투구, 번역투, 이모지, 문장 길이가 다 똑같은 것 |
| **같은 글 반복** | 지난 글과 내용이 겹치는 것 |
| **같은 학생 반복** | 최근 다섯 편에 나온 사례를 또 쓰는 것 |

마지막 항목이 특히 중요해요. 매번 같은 아이 이야기가 나오면
학부모가 *"이 학원엔 저 학생밖에 없나"* 생각해요.

> **법률 판단을 해드리는 건 아니에요.**
> 학원 광고에서 문제가 됐던 표현들을 모아 **미리 걸러드리는 것**이에요.
> 걸렀다고 안전하다는 보증은 아니고, 안 걸렸다고 위험하다는 뜻도 아니에요.
> 애매한 표현은 원장님이 판단하시고, 정말 중요한 문안은 전문가에게 물어보세요.

> **다만 반복이 전부 나쁜 건 아니에요.**
> 원장님이 즐겨 쓰시는 문장은 클리셰가 아니라 **시그니처**예요.
> 지우시면 안 쓰는 표현으로, 남기시면 브랜딩 문장으로 배워요.
> **판단은 원장님이 하시고 저희는 여쭤보기만 해요.**

## 자주 묻는 것

**Q. 폴더 구조를 알아야 하나요**
`_여기에_넣으세요` 하나만 기억하시면 돼요. 나머지는 저희가 해요.

**Q. 글이 마음에 안 들어요**
그냥 말씀하세요. "3번 문단이 딱딱해요" 하시면 고쳐요.
직접 고치셨으면 `/피드백` 으로 알려주세요. 다음 글부터 반영해요.

**Q. 사례가 없는데요**
`/사례추가` 로 넣으시면 돼요. 지난달 상담 기록도 사례가 돼요.
상담하면서 들으신 질문 하나하나가 다 글감이에요.

**Q. 자동으로 블로그에 올려주나요**
아니요. **일부러 안 해요.** 네이버는 자동 발행을 매크로로 보고 제재해요.
몇 년 쌓으신 블로그를 걸 수 없어요. 복사해 붙이는 5분이 그 위험보다 싸요.

**Q. 얼마나 자주 써야 하나요**
주 1~3편이 안전해요. 하루에 여러 편 올리는 건 오히려 위험해요.

**Q. 쓸수록 좋아지나요**
네. 그게 설계 목적이에요. `/피드백` 을 쓰실수록 편집률이 줄어들어요.
숫자로 보여드리니 좋아지고 있는지 직접 확인하실 수 있어요.

**Q. 뭔가 잘못된 것 같아요**
`/점검` 을 돌려보시고 결과를 그대로 물어보세요.
